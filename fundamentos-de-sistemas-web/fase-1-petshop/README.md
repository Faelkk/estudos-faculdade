# Petshop Amigo Fiel

## Objetivo

Apresentar a estrutura inicial de uma plataforma online para visualização dos produtos e serviços de um petshop.

## Funcionalidades disponíveis

- Apresentação do petshop;
- Navegação entre as quatro páginas;
- Visualização de produtos com nome, imagem, descrição e valor;
- Visualização de serviços de banho e tosa com valores e informação de tele-busca;
- Consulta aos dados fictícios de contato e horários.

O projeto não possui login, cadastro, carrinho, pagamento, pesquisa, filtros, agendamento ou outras funções interativas.

## Categorias apresentadas

- Acessórios;
- Rações não perecíveis;
- Produtos de higiene e limpeza.

Cada categoria possui dois produtos.

## Serviços apresentados

- Banho sem tele-busca;
- Banho com tele-busca;
- Tosa sem tele-busca;
- Tosa com tele-busca.

## Estrutura das páginas

- `index.html`: apresentação do petshop e resumo do site;
- `produtos.html`: três categorias e seis produtos;
- `servicos.html`: serviços de banho e tosa;
- `contato.html`: endereço, telefone, e-mail e horários fictícios.

As imagens utilizadas pelo site estão na pasta `imagens`.

## Tecnologias utilizadas

- HTML5.

Esta fase utiliza somente HTML. Não foram utilizados CSS, Bootstrap, JavaScript, frameworks, gerenciadores de pacotes, servidor, API ou banco de dados.

## Como abrir o site localmente

1. Baixe ou copie a pasta do projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Use os links de navegação para acessar as demais páginas.
